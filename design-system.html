03 — Espaciado

Escala de Espaciado Modular

Sistema de espaciado en potencias de 2 para crear ritmos verticales armónicos. Todos los valores son relativos (rem) para respetar las preferencias del usuario.

--space-xs = 0.25rem (4px) — Separaciones mínimas, gap de íconos.
--space-sm = 0.5rem (8px) — Gaps entre tags/badges.
--space-md = 1rem (16px) — Padding interno de tarjetas y formularios.
--space-lg = 2rem (32px) — Gaps de grillas, separación entre secciones de skills.
--space-xl = 4rem (64px) — Padding vertical de secciones grandes.
--space-2xl = 6rem (96px) — Padding entre secciones hero/principal.
--space-3xl = 8rem (128px) — Padding mínimo del hero en desktop.
Token rem px Uso principal

--space-sm 0.5rem 8px Gap entre badges, padding de chips

--space-lg 2rem 32px Gap entre skill cards, padding de bloques
--space-xl 4rem 64px Padding vertical de secciones
